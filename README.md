# Sports-Data-Analytics
1. Conducted end-to-end data analysis on 500+ players performance dataset: performed data cleaning, exploratory data analysis (EDA), and statistical testing (Hypothesis Testing, Shapiro–Wilk for normality).

2. Applied Yeo-Johnson transformation to normalise columns.
   
3. Pre-Processed Data: Feature Scaling (StandardScaler) to scale all the features, followed by PCA for dimensionality reduction to reduce complexities of the model.

4. Implemented K-Means clustering to segment players into 4 performance categories, enabling identification of top-performing and supporting players with actionable insights.
