# Sports-Data-Analytics
<h3>Conducted descriptive, exploratory and predictive data analysis on dataset, including 500+ players performance records, using Python (libraries such as pandas, numpy, scipy, matplotlib, seaborn, and scikit-learn)</h3>
<p><b>Performed following tasks:</b>
 <ul>
 <li>Performed data cleaning, handle missing values using <b>SimpleImputer</b></li>
 <li>Performed data manipulation, exploratory data analysis (EDA).</li>
 <li>Applied statistical tests (Hypothesis Testing) to check statistical significance of features.</li>
 <li>Applied <b>Shapiro–Wilk test</b> to check normal distribution and applied <b>Yeo-Johnson transformation</b> to normalise columns.</li>
 <li>Data Pre-Processing: <b>Feature Scaling (StandardScaler)</b> to scale all the features, followed by <b>PCA</b> for dimensionality reduction to reduce complexities of the model.</li>
 <li>Data Mining: Implemented <b>K-Means clustering </b>method to segment players into 4 performance categories, enabling identification of top-performing and supporting players with actionable insights.</li>
 <li>Evaluate the model performance using <b>Silhoutte Score and Davies-Bouldin Index</b> to measure cluster cohesion and separation.</li>
 </ul>
